# 2026-10-02

## 雄亿仪器网 WordPress → Hexo 迁移 + 自研主题

**背景**：`output/` 目录是 `WordPress.2026-10-02.xml` 经 wordpress-export-to-markdown v3.0.6 转换的产物（192 篇文章 + 2 个页面 + 321 张图片）。

**交付物**
1. **Hexo 站点骨架**：`_config.yml`、`package.json`（Hexo 8.1.2）、`scaffolds/`、`.gitignore`
2. **自研主题 `themes/xongyi/`**：B2B 仪器展示风（工业蓝），含
   - 布局：`layout.ejs` / `index.ejs` / `post.ejs` / `page.ejs` / `archive.ejs` / `category.ejs` / `tag.ejs` / `categories.ejs` / `search.ejs`
   - 部件：`_partial/`（head / header / footer / product-card / pagination / page-head / totop）
   - 资源：`source/css/style.css`（约 700 行，响应式 + 断点 1080/820/520）、`source/js/main.js`（移动导航 / 返回顶部 / 图片灯箱 / 站内搜索）
   - 语言包：`languages/zh-CN.yml`、`en.yml`；配置 `_config.yml`（分类中文名、公司信息、首页文案、功能开关）
3. **内容迁移**：`tools/migrate.py`（Python）→ 生成 `source/_posts/<slug>.md`、`source/<slug>/index.md`、`source/images/<slug>/`
4. **Hexo 扩展脚本**（`scripts/`）：
   - `theme-helpers.js`：`cat_name/cat_desc/cat_url/cat_count/cat_posts/cat_icon`、`xy_url`、`first_image`、`plain_excerpt`、`primary_category`、`in_category`、`related_posts`
   - `search-generator.js`：生成 `/search.json` 站内搜索索引

**关键技术点 / 踩坑**
- **Hexo 多分类是层级关系**：`categories: [a, b]` 会生成 `a/b` 嵌套分类。要表达互不相关的多个分类必须写 `categories:\n  - [a]\n  - [b]`（见 `hexo/dist/models/post.js` 的 `setCategories`，`hasHierarchy` 分支）。
- **`hexo-generator-category` / `-tag` 传给模板的 `page.category` / `page.tag` 是「字符串名」，不是对象**（`data: { category: category.name }`）。早期按 `page.category.name` 取值导致标题为空、计数为 0。
- **同名分类要只取顶级**：helper 里用「无 parent 优先」的查找，避免同名子分类抢占 `findOne`。
- **`scripts/*.py` 会被 Hexo 当 JS 加载而报错**，迁移脚本已移到 `tools/`。
- 图片统一改为根路径 `/images/<slug>/<file>`，与 permalink 解耦；permalink 用 `:title/`（扁平、带尾斜杠）。
- WP `[caption]` 短代码转 `<figure class="wp-caption">`；WP 把整块 HTML 塞进单列表格单元格的内容做了「拆表格」还原。
- Windows 上 `hexo clean` 删除 1000+ 文件极慢（曾达 15 分钟），日常改动用 `hexo generate` 覆盖即可。
- 项目内自带 `node_modules`，命令用 `./node_modules/.bin/hexo`。

**校验结果**：生成 1055~1060 个文件；730 个 HTML；`真实无效内部链接 = 0`、`缺失图片引用 = 0`；`search.json` 192 条。

## 修复：整站蒙板常驻（用户反馈）

- **原因**：`.lightbox { display:flex }` 覆盖了 UA 样式的 `[hidden]{display:none}`，灯箱（深色全屏遮罩）即使带 `hidden` 也一直显示；`.totop` 同理。
- **修复**：`themes/xongyi/source/css/style.css` reset 区加 `[hidden] { display: none !important; }`，重新 generate。
- **验证**：agent-browser 截图首页 + 产品详情页（ppshuicao），蒙板消失、渲染正常。
- 已把该坑记入技能 `wordpress-to-hexo-migration/references/hexo-pitfalls.md` 第 7 条。
